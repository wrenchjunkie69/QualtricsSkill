# Instrument pilot and verification plan

Select checks relevant to the instrument and authorized task. Keep comprehension review, definition/readback checks and retained-response/export checks distinct; success in one does not establish the others. This plan does not itself authorize contacting participants, retaining test responses or using screen control.

| Case | What to check | Expected result | Actual evidence / result | Revision or remaining limitation |
|---|---|---|---|---|
| Key research measure | Ask an appropriate reviewer to explain interpretation and recall process | Intended construct, context and response options are understood | | |
| Eligibility boundary | Eligible and ineligible cases, including unknown/refused input | Correct route/disposition; no inappropriate downstream questions | | |
| Inapplicable or omitted answer | A truthful none/unfamiliar/not-applicable choice and a skipped item | Distinct coding where meaningful; no forced invented answer | | |
| Validation boundary | Valid zero/endpoints and invalid values; exclusive multi-select options | Intended rules accepted/rejected without preventing truthful responses | | |
| Assignment or order | Experimental condition, randomized content and fixed ordered scales | Intended exposure/order; stable assignment/task IDs and codes | | |
| Definition and flow | API readback of text, choices, recodes, blocks and branches | Matches the requested specification and preserves required IDs | | |
| Retained test export | Selected labels/codes, skips, counts and respondent/task mapping | Export matches the test case; test provenance distinguishable | | |
| Burden and access | Relevant reviewer/device/access needs, when such review is available | Understandable, manageable tasks; observed time supports estimate | | |

Record the tested instrument version, changes and retested cases. Mark checks not performed rather than implying they passed. If only programmatic readback was possible, state that comprehension/rendering or actual retained-response behavior remains unverified. Publication and invitations require the user's requested scope.
