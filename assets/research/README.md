# Optional research-design templates

Select these when the requested deliverable benefits from a saved planning artifact. A narrow item edit or data export does not require completing all of them. Copy/adapt into the user's project rather than filling the installed skill's originals.

- [Research brief](research-brief.md): clarify the decision, evidence gap, questions, design and practical constraints.
- [Question blueprint](question-blueprint.md): connect objectives to measures, respondent items, coding, logic and analysis.
- [Pilot plan](pilot-plan.md): record intended paths/measurement checks, evidence and unresolved limits.
- [Selected analysis plan](analysis-plan.md): define units, feature timing, method, baseline, validation and scenario assumptions for a requested analysis.

These are editable planning structures, not questionnaires, validated scales, participant records or executable launch instructions. Use [research planning](../../references/research-planning.md) and [questionnaire design](../../references/questionnaire-design.md) for the relevant decisions. They contain no account IDs or credentials, and using them does not authorize collection, publication or analysis outside the user's request.
